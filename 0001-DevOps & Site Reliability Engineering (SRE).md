# VYOMANANT ACADEMY

## DevOps & Site Reliability Engineering (SRE)

### 16-Day Corporate Training Program — Module-Wise & Day-Wise Course Outline

**Training Model:** Instructor-Led | Hands-On | Project-Based\
**Duration:** 16 Days\
**Level:** Foundation to Intermediate\
**Delivery Mode:** Online / Classroom / Corporate Workshop\
**Practical Focus:** Three Industry-Oriented DevOps Projects

# 🌍 Program Overview

This intensive 16-day DevOps and SRE training program is designed to equip participants with practical skills in cloud infrastructure automation, Continuous Integration and Continuous Deployment (CI/CD), Kubernetes, GitOps, and Site Reliability Engineering.

The program combines essential technical concepts with guided demonstrations and hands-on implementation of three DevOps projects.

## 🎯 Key Project Deliverables

| Project    | Project Title                                  | Core Technologies                           |
| ---------- | ---------------------------------------------- | ------------------------------------------- |
| Project 01 | Cloud Infrastructure Automation                | Terraform, Ansible, AWS EKS, Azure AKS      |
| Project 02 | End-to-End CI/CD Pipeline Implementation       | Jenkins, GitHub, Docker, Kubernetes         |
| Project 03 | GitOps-Based Kubernetes Application Deployment | GitHub Actions, Docker, Kubernetes, Argo CD |

# 📚 Module 01 — DevOps Foundations & Application Architecture

DAYS 01–03 | FOUNDATION & TECHNICAL READINESS

### Day 01 — Introduction to the DevOps and SRE Ecosystem

- Software Development Life Cycle (SDLC) and Agile fundamentals
- DevOps principles, culture, lifecycle, and industry adoption
- Introduction to CI/CD, Infrastructure as Code (IaC), and automation
- Overview of containers, Kubernetes, cloud computing, and GitOps
- Introduction to Site Reliability Engineering (SRE)
- Understanding the modern DevOps toolchain and engineer responsibilities

Practical Delivery: Demonstration of an end-to-end DevOps lifecycle and its associated tools.

### Day 02 — Linux, Networking, Git & GitHub Fundamentals

- Essential Linux commands, filesystem, users, permissions, and processes
- Networking fundamentals: IP, DNS, ports, SSH, HTTP/HTTPS
- Introduction to Git and distributed version control
- GitHub repositories, branching, commits, push, pull, and clone
- Repository collaboration and basic troubleshooting

Practical Delivery: Linux command-line exercises and Git/GitHub repository operations.

### Day 03 — Understanding the Project Application & Microservices Architecture

- Introduction to the application used throughout the projects
- Understanding application repository structure and components
- Microservices architecture and inter-service communication
- Frontend, backend, APIs, and application dependencies
- Introduction to Dockerfiles and Kubernetes deployment manifests
- Understanding the application build and deployment workflow

Practical Delivery: Application repository walkthrough and architecture mapping.

# ☁️ Module 02 — Project 01: Cloud Infrastructure Automation

DAYS 04–06 | TERRAFORM, ANSIBLE, AWS EKS & AZURE AKS

### Day 04 — Infrastructure as Code (IaC) with Terraform & Ansible

- Infrastructure automation concepts and business benefits
- Terraform architecture, providers, resources, and state management
- Terraform workflow: Initialize, Plan, Apply, and Destroy
- Variables, outputs, and reusable infrastructure configurations
- Introduction to Ansible, inventories, and playbooks
- Terraform versus Ansible and their complementary roles

Practical Delivery: Terraform and Ansible configuration walkthrough with foundational IaC exercises.

### Day 05 — Understanding Terraform Project Structure for AWS EKS & Azure AKS

- Overview of Project 01 and its implementation architecture
- Understanding the supplied Terraform scripts and directory structure
- AWS and Azure provider configuration
- Kubernetes infrastructure requirements and dependencies
- Networking, security, IAM/RBAC, and cluster configuration
- Understanding infrastructure provisioning workflows for EKS and AKS

Practical Delivery: Project configuration analysis, environment preparation, and Terraform validation.

### Day 06 — Hands-On Implementation: Kubernetes Cluster Provisioning on AWS & Azure

- Preparing AWS and Azure environments
- Executing Terraform infrastructure provisioning workflows
- Provisioning Amazon Elastic Kubernetes Service (EKS)
- Provisioning Azure Kubernetes Service (AKS)
- Configuring Kubernetes cluster access
- Validating nodes, namespaces, and cluster connectivity
- Infrastructure troubleshooting and resource cleanup

Practical Delivery: Guided execution and validation of Project 01 across supported cloud environments.

# 🔄 Module 03 — Project 02: End-to-End CI/CD Pipeline with Jenkins

DAYS 07–10 | JENKINS, GITHUB, DOCKER & KUBERNETES

### Day 07 — Introduction to CI/CD with Jenkins, GitHub Actions & GitLab CI/CD

- Continuous Integration, Continuous Delivery, and Continuous Deployment
- CI/CD pipeline architecture and execution stages

- Overview of GitHub Actions and workflow automation

- Understanding build, test, package, and deployment workflows

### Day 08 — Jenkins CI/CD Project Architecture & Implementation Planning

- Introduction to Project 02 and its business objectives
- Understanding the end-to-end Jenkins CI/CD architecture
- Jenkins controller, agents, plugins, and integrations
- GitHub repository integration and webhook concepts
- Docker image build and container registry workflow
- Kubernetes deployment integration
- Understanding Jenkinsfile structure and pipeline stages

### Day 09 — Hands-On Implementation: Continuous Integration Using Jenkins

- Configuring Jenkins pipeline jobs
- Integrating Jenkins with the GitHub repository
- Automating source code checkout
- Application build and test execution
- Building Docker container images
- Configuring container registry authentication
- Publishing container images
- CI pipeline execution and troubleshooting

Practical Delivery: Implementation and validation of the Jenkins Continuous Integration pipeline.

### Day 10 — Hands-On Implementation: Continuous Delivery/Deployment Using Jenkins

- Understanding the Jenkins CD workflow
- Configuring Kubernetes deployment integration
- Preparing application deployment manifests
- Automating deployment stages through Jenkins

- Validating application availability and rollout status

- Introduction to Project 03 and its business objectives
- GitOps principles and declarative infrastructure management
- Understanding GitHub Actions workflow architecture
- GitHub Actions runners, jobs, steps, and triggers

### Day 12 — Hands-On Implementation: Continuous Integration Using GitHub Actions

- Creating and configuring GitHub Actions workflows
- Configuring workflow triggers and repository secrets
- Automating application build and testing
- Building Docker images using GitHub Actions
- Container image tagging and registry authentication
- Publishing images to a container registry
- Monitoring workflow execution and troubleshooting

Practical Delivery: Implementation and successful execution of the Project 03 GitHub Actions CI workflow.

### Day 13 — Hands-On Implementation: Continuous Delivery Using Argo CD

- Understanding Argo CD deployment architecture
- Installing and accessing Argo CD
- Connecting the GitOps repository
- Creating and configuring Argo CD applications
- Deploying Kubernetes workloads using GitOps
- Synchronization, application health, and drift detection
- Updating application deployments through Git
- Validating deployment changes and troubleshooting

Practical Delivery: End-to-end GitOps application deployment using GitHub Actions and Argo CD.

# 📊 Module 05 — Application Observability & Site Reliability Engineering

DAYS 14–15 | MONITORING, LOGGING, RELIABILITY & OPERATIONS

### Day 14 — Introduction to Application Monitoring, Logging & Observability

- Importance of monitoring in DevOps environments

- Introduction to dashboards, alerts, and incident detection

- Service availability, reliability, and performance
- Service Level Indicators (SLIs), Objectives (SLOs), and Agreements (SLAs)
- Error budgets and reliability engineering
- Incident management and escalation workflows
- Troubleshooting, recovery, and rollback strategies
- Root Cause Analysis (RCA) and post-incident reviews
- Day-to-day responsibilities of an SRE engineer

# 🎯 Expected Training Outcomes

At the end of the program, participants will have gained practical exposure to:

- Cloud Infrastructure Automation: Understanding and implementing repeatable infrastructure provisioning with Terraform and Ansible.
- Cloud-Native Kubernetes: Provisioning and validating managed Kubernetes clusters on AWS and Azure.
- Jenkins CI/CD: Building and executing automated application integration and deployment pipelines.
- GitHub Actions: Automating application build, test, and container image publishing workflows.
- GitOps with Argo CD: Managing Kubernetes application deployments through Git-based desired-state configuration.
- Monitoring and Observability: Understanding application health, logs, metrics, dashboards, and alerts.
- Site Reliability Engineering: Applying reliability concepts, troubleshooting practices, and incident response fundamentals.
